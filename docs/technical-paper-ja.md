# AIトレーサー なぞり君 v0.1.3 技術報告

2026年11月25日 · FURU

## 概要

ラスターのイラストを下絵として読み込み、ペン入れと彩色をブラウザー上で順に再生する。出力は2次元の画像、閉経路、色別レイヤーとして利用できる。処理はブラウザー内で行い、外部APIに原稿を送信しない。利用時のAPIキーは不要である。

実装にはAIコーディング支援を使った。トレスと元色の復元には画像処理アルゴリズムを用いる。

## 処理方式

1. **線の抽出。** モノクロでは透過を考慮した輝度を使う。カラーでは暗さ・彩度・両側との明暗差から、細い線を暗いベタ面と分けて拾う。
2. **インクの再構築。** インクの外周を閉経路として取り出す。内側の穴も保持し、走査線との交点を使って塗り戻す。Gペンでは近傍のインク密度から先端と太い部分に異なる強さを与える。丸ペン、筆ペン、輪郭そのままの設定も比較できる。
3. **時間と筆先。** 閉経路を順番にたどる。ペンカーソルが通過した近傍からインクを表示し、広い部分では内側へ伝える。筆順は元絵の輪郭から再構成する。原作者の筆跡データを復元する方式とは区別する。
4. **彩色。** カラー原稿の代表色を抽出し、線と色の分布で領域を分ける。描画済みの線の上で筆先を動かし、色面内を走査した順に色を表示する。モノクロ原稿は線画を出力する。カラー原稿の色は原稿ごとにレイヤーを作り、利用者がレイヤー単位で変更できる。

## 保存と連携

PNGは合成画像、PSDは透過のペン層、色ごとの層、用紙を出力する。SVGはペンの輪郭と色面をパスで持つ。座標JSONは原稿左上を原点とするピクセル座標を持つ。WebMは再生による工程の記録である。プロジェクトJSONは原稿、ペン設定、色指定、境界、速度を保持する。

ローカルMCPは標準入出力で動く。指定した専用フォルダーのPNGを読み、PNG・PSD・SVG・座標JSONを新しいサブフォルダーへ書き出す。

## 検証と適用範囲

均一な細線を使ったモノクロの時計職人と、衣装・刺繍・背景を含むカラーの凧職人を、内蔵Chromium上でGペン100%で検証した。凧職人は起動時の原稿、時計職人は画像一覧の2枚目に配置した。カラー2例でペン入れから彩色への切り替えを確認した。書き出したPSDをPhotoshop 2026で開き、ペンと色の下に用紙が配置され、絵が表示されることをカラーとモノクロで確認した。カラーの検証原稿はペン1層、色34層、用紙1層で構成していた。編集画面で1色だけの変更、取り消し・やり直し、詳細プロジェクトの保存・復元も検証した。

写真や連続したグラデーションには色の近似が入る。暗色の重なりや薄い境界は入力に応じた調整が必要になる。
